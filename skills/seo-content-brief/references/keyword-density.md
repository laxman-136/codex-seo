# Keyword placement guardrails

Google does not require a fixed keyword density. Use density only as a post-draft
quality-control signal, never as a ranking guarantee.

## Exact-match primary keyword

| Density | Review guidance |
|---|---|
| Below 0.5% | Check whether the page clearly establishes its main topic. |
| 0.5%-2.0% | Generally natural when placements are contextually accurate. |
| 2.0%-3.0% | Review for repetition and awkward phrasing. |
| Above 3.0% | High keyword-stuffing risk. Rewrite for readers. |

The first accurate mentions and key placements matter more than repetition.

## Required placement review

Check for a natural primary-topic reference in:

1. Title tag
2. H1
3. URL slug
4. Meta description
5. First paragraph/first 100 words
6. One relevant image alt attribute

It is not required in every H2, paragraph, or internal-link anchor.

## Secondary coverage

- Use 5-8 closely related terms where they support intent.
- Add broader entities, concepts, questions, and synonyms needed for full coverage.
- Distribute terms naturally rather than clustering them near the top.
- Give each outline section a specific topic/keyword role.
