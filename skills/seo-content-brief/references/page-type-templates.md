# Page-type templates

Use these as planning structures, not mandatory boilerplate. Remove sections that
the verified business, intent, or evidence cannot support.

## Service page

Definition; audience/use cases; process; costs/timelines; outcomes/proof;
differentiators; FAQs; conversion action.

## Blog post

Direct answer; context; core concepts; practical process; examples/decision criteria;
common mistakes; FAQs; contextual next step.

## Case study

Outcome summary; client situation; challenge; approach; measured result; limitations;
key takeaways; related solution.

## Category or hub page

Category definition; one section for every verified child page; selection criteria;
audiences; process; FAQs; next step. Every child section requires an internal link.

## Landing page

Outcome-led hero; problem; benefits; proof; process; offer details; objections/FAQs;
one repeated primary CTA.

## FAQ page

Group 8-15 questions by intent. Use concise direct answers and link to deeper pages.
Do not promise FAQ rich results; structured data eligibility changes over time.

## Location page

Local service context; verified offerings; areas served; local expertise/process;
local proof/team; location-specific FAQs; local contact action.

## About page

Positioning; story; team credentials; how the organisation works; proof/recognition;
links to services and contact.

## Homepage

Value proposition; core services/products; evidence-led differentiators; process;
proof; locations/service area; broad FAQs; primary CTA.

## Comparison page

Quick verdict; at-a-glance table; fair overview of each option; criterion-by-criterion
comparison; total value; scenario-based recommendation; FAQs.

## Product page

Overview; feature-benefit mapping; specifications/compatibility; use/implementation;
verified proof/reviews; price/delivery/returns; FAQs; purchase action.
